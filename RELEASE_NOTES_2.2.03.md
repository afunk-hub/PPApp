# Prairie Preludes Creator Studio 2.2.03

- Expanded Upcoming Video Readiness from seven days to the next 14 days.
- Added a separate Upcoming Photo Readiness section for photo projects.
- Video readiness now shows exactly: Planned video, Date, Audio, Video, Caption.
- Photo readiness now shows exactly: Planned photo, Date, Photo, Caption.
- Assignment status is based on linked audio, video, photo, and non-empty caption data.
- Both sections sort by planned publish date, soonest first.
- Both sections exclude projects marked Published and projects without a planned publish date.
- Sections refresh through the existing Command Center render flow when project data changes.
