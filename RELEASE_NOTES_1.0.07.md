# Prairie Preludes Creator Studio — Version 1.0.07

## What's new
- Added **Filming Setup** to the Footage Asset Record.
- Fixed dropdown options: Handheld, Flow 2 Pro Gimbal, Tripod, and Gimbal + Tripod.
- The selected setup is saved with the asset, restored when editing, and shown in the Footage Catalog.
- Existing footage records remain compatible; records without a selected setup display an em dash.
- Updated app version, backup/CSV export filenames, manifest description, and service-worker cache.

## Deployment note
Back up local app data before deploying. This is a patch package; keep existing logo/icon files and other repository files that are not included here.
