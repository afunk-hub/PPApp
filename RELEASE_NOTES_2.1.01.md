# Prairie Preludes Creator Studio 2.1.01

## Series color palette update
- Replaced the unrestricted series color picker with ten curated Prairie Preludes colors: Sage, Deep Sage, Prairie Olive, Wheat, Amber Grass, Terracotta, Dusty Rose, Muted Plum, Storm Blue, and Eucalyptus.
- Added labeled, keyboard-focusable color swatches and a selected-color preview.
- Existing series colors are preserved when loading and editing existing series; choosing a palette swatch updates that series color.
- Existing Series Manager, calendar, Command Center, readiness dashboard, and backup/restore behavior remain unchanged.

## Deployment
Replace `index.html` and `sw.js` at the GitHub Pages site root. Keep existing manifest and icon assets. Export a JSON backup before updating.
