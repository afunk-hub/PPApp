# Prairie Preludes Creator Studio 2.0.08

## Upload tracking and posting-time analytics
- Added a required 24-hour upload-time selector in complete 2-hour windows (00–02 through 22–24).
- Upload records now display their selected upload-time window.
- Added performance-by-upload-time analytics for 7-, 30-, 90-day, and lifetime snapshots.
- Analytics show video count, total views, average views per video, engagement rate, average recorded watch minutes per video, and followers gained.
- Default comparison covers short-form platforms; platform filtering supports Instagram, Facebook, TikTok, YouTube Shorts, and a separate YouTube Long Format analysis.
- The All short-form platforms option creates four individual upload records: Instagram, Facebook, TikTok, and YouTube Shorts.
- Added distinct YouTube Shorts and YouTube Long Format options to upload and planning workflows.
- Existing records and snapshot data are preserved. Existing upload records without a recorded upload time are labeled Not recorded and excluded from time-window analytics until recreated/updated in a future editing workflow.

## Deployment
Replace the existing index.html and sw.js in the GitHub Pages site root. The versioned PrairiePreludes2.0.08.html is also included as the versioned standalone app file. Keep other app files and all locally stored app data unchanged. Export a fresh backup before updating any installed copy.
