# Prairie Preludes Creator Studio 1.0.03

## Changes
- Added an **Edit** action to each footage catalog entry.
- Existing record details load back into the footage form for editing.
- Saving an edit updates the existing record instead of creating a duplicate.
- Added Cancel edit; deleting the record currently being edited exits edit mode.
- Preserved existing footage records and local-first storage behavior.
- Updated versioned HTML, manifest, and service-worker cache for 1.0.03.
