Prairie Preludes Creator Studio 2.0.03 — GitHub Pages deployment

1. Keep your external JSON backup stored somewhere outside the app.
2. Extract this ZIP.
3. Open the `GitHub-Pages` folder.
4. Upload the CONTENTS of `GitHub-Pages` into the existing GitHub repository `PPApp/` folder. Do not upload the `GitHub-Pages` folder as a nested folder.
5. Replace the existing `index.html`, `sw.js`, and `manifest.webmanifest`; keep/replace the three image assets.
6. Do NOT upload `Release-Archive/PrairiePreludes2.0.03.html` to GitHub Pages. It is archival only.
7. Commit and wait for GitHub Pages deployment.
8. Test `https://afunk-hub.github.io/PPApp/` and confirm the footer shows 2.0.03.
9. The service worker should pre-cache `index.html`; no versioned HTML file is required.

Do not clear Chrome site data or uninstall the app as a deployment step.
