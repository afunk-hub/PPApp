# Prairie Preludes Creator Studio 1.0.04

## Changes
- Added a **Video length** field to footage asset records (for example, `00:45` or `01:23:10`).
- Added a **Video filter** field (for example, ND filter, polarizer, or none).
- Both values save with the footage record, load when editing, and appear in the footage catalog.
- Existing records remain compatible; fields are blank until filled in.
- Updated versioned HTML, manifest, and service-worker cache for 1.0.04.

## GitHub Pages
Upload the contents of this package to the repository root, replacing the older files. `index.html` is the site entry point.
