# Prairie Preludes Creator Studio 1.0.06

## Added
- Dedicated **Footage Usage** tab.
- Summary counts for footage assets, reused assets, unique video edits linked to footage, and platform upload entries linked to footage.
- Search, usage filters, and sorting for footage usage.
- Per-asset upload history with platform, publication date, and available publication links.

## Data and compatibility
- Usage is calculated from existing footage asset records and `assetIds` links on upload records.
- No new storage database or migration is required. Existing local records are preserved.
- Export a JSON backup before updating as a normal precaution.
