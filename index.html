Local data and backup

Records are stored in this browser on this device. Clearing browser data or uninstalling may remove records. Export backups regularly and keep them somewhere safe. The app does not automatically sync between devices.

Backup status will appear here.
Two layers of protection: Creator Studio keeps an on-device safety copy to help recover if its main catalog entry is damaged or missing. This is not an external backup and can still be lost if site data is cleared or the app storage is removed. Use Export JSON backup and keep the downloaded file outside the app.

Imports are previewed before you choose to merge or replace. Keep a dated backup outside this browser. The displayed backup date records exports made from this app on this browser only.

Install on Android

  1. Host this app on a secure HTTPS site (or use a compatible local web server).
  2. Open the site in Chrome on Android.
  3. Use Chrome’s menu and choose Install app or Add to Home screen.

The downloaded package includes a manifest and service worker. A service worker and install prompt require an HTTPS origin (localhost is allowed for development); opening the HTML file directly is not enough for full PWA installation.

Privacy

This is a local-first tracker. No analytics or external services are included. Platform metrics must be entered manually; the app does not connect to social media accounts.
