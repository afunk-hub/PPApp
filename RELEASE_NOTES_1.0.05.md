# Prairie Preludes Creator Studio 1.0.05

## New in 1.0.05
- Link one or more footage assets to each video upload entry.
- Review associated footage directly in the Video uploads table.
- Edit footage links on existing upload entries.
- Footage catalog now shows usage frequency, unique video-edit count, platform-entry count, first/last use, and linked upload history.
- Usage is calculated from saved upload-to-asset relationships and updates when links or records change.
- Backup export version label updated to 1.0.05.

## Data and privacy
Records remain in this browser's local storage. GitHub Pages hosts the app, not the records entered into it. Export JSON backups regularly. This release does not automatically migrate any external records; existing records remain in the same browser storage key.
